## Why Stylet?

- ⚡ **Zero-config** — drop in one `<link>` and go
- 🎬 **Animation-first** — a declarative motion system, not an afterthought
- 🎨 **Token-driven** — retheme the entire framework with CSS variables
- 🌙 **Automatic dark mode** — no extra classes needed
- 📱 **Fluid by default** — `clamp()` typography, container queries
- 🧩 **Semantic + utility hybrid** — write clean HTML or go atomic
- 🪶 **Tiny** — under 15KB minified + gzipped
